# Conforma — Portfolio asset package

Delivery-ready assets for publishing Conforma to **Upwork Portfolio**, the
**Upwork Project Catalog**, and **GitHub**. Every image here is captured from, or
derived from, the **live production app** at
**<https://conforma-ten.vercel.app>** — nothing is mocked up or hand-drawn.

- **Full-resolution screenshots** live in [`../screenshots/`](../screenshots) (2× retina, generated by `npm run screenshots`).
- **Covers** in [`covers/`](covers) are cropped/downscaled from those screenshots by `npm run covers`.

Regenerate everything from scratch:

```bash
npm run build && npm start                              # or point at the live URL:
SCREENSHOT_BASE_URL=https://conforma-ten.vercel.app npm run screenshots
npm run covers
```

## Demo video (`conforma-demo.mp4`)

An ~80-second product tour, recorded end-to-end against the **live production
app** — landing hero → light/dark theme → guided classifier → dashboard → ⌘K
command palette → system detail (live obligation toggle) → readiness report → a
responsive mobile beat. 1280×720, H.264, web-optimised (`+faststart`).

| File | What |
| --- | --- |
| `conforma-demo.mp4` | The product-tour video (client- and portfolio-ready) |
| `conforma-demo-poster.png` | Poster / thumbnail frame (the seeded dashboard) |

Regenerate from the live app (or any base URL):

```bash
DEMO_BASE_URL=https://conforma-ten.vercel.app npm run demo:video
```

The recorder auto-trims any cold-load black lead-in, so the video always opens on
content, and grabs the poster frame automatically.
